# Crypto Dashboard - Enhanced Version

## 📊 نظرة عامة

لوحة تحكم متقدمة لتحليل الاستثمار في العملات المشفرة مع ميزات تفاعلية شاملة وتحليلات متقدمة.

## 🚀 الميزات الجديدة

### 📈 **الصفحات المتعددة**
- **📊 ملخص تنفيذي**: نظرة شاملة على الأداء مع مؤشرات متقدمة
- **🔄 المعاملات**: عرض تفاعلي للمعاملات مع بحث وفرز
- **🧮 تحليل FIFO**: تحليل مفصل لطريقة FIFO
- **📈 الرسوم البيانية المتقدمة**: رسوم بيانية تفاعلية باستخدام Plotly
- **📤 التصدير والمشاركة**: تصدير البيانات ومشاركة التقارير
- **⚠️ تحليل المخاطر**: تحليل شامل للمخاطر ومؤشرات الأداء

### 🔍 **فلاتر تفاعلية متقدمة**
- نطاق تاريخ ديناميكي
- اختيار متعدد للعملات
- فلتر حجم المعاملات
- فلتر الربح/الخسارة
- تحديث تلقائي للبيانات

### 📊 **مؤشرات الأداء المتقدمة**
- نسبة الربح/الخسارة (Win Rate)
- معامل الربح (Profit Factor)
- مؤشر شارب (Sharpe Ratio)
- أقصى انخفاض (Max Drawdown)
- مؤشر كالمر (Calmar Ratio)
- مؤشر سورتينو (Sortino Ratio)
- Value at Risk (VaR)
- Conditional VaR (CVaR)

### 📈 **رسوم بيانية متقدمة**
- رسم بياني خطي تفاعلي
- أعمدة ملونة حسب الأداء
- الرسم التراكمي للأرباح
- مخطط التشتت (Scatter Plot)
- تحليل حجم التداول
- رسوم بيانية للمخاطر

### 🔔 **نظام التنبيهات**
- تنبيهات الأسعار
- تنبيهات الأداء
- تنبيهات المخاطر
- إشعارات فورية
- قوالب جاهزة

### 📤 **التصدير والمشاركة**
- تصدير CSV
- تصدير Excel
- تصدير JSON
- روابط المشاركة
- إعدادات التصدير المخصصة

## 🛠️ التثبيت والتشغيل

### 1. **تثبيت المكتبات**
```bash
pip install -r requirements.txt
```

### 2. **تشغيل لوحة التحكم**
```bash
# التشغيل من المجلد الرئيسي
streamlit run dashboard/enhanced_app.py

# أو التشغيل من مجلد dashboard
cd dashboard
streamlit run enhanced_app.py
```

### 3. **تشغيل النظام الكامل**
```bash
# تشغيل تطبيق سطح المكتب
python app_desktop.py

# تشغيل جميع العمليات
python main.py
```

### **مشاكل شائعة**

3. **أداء بطيء**: استخدم الفلاتر لتقليل حجم البيانات
